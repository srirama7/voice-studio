# 🎙️ Voice Studio Enterprise

Zero-shot voice cloning + presentation-to-speech studio with 38 Indian voices
(English, Hindi, Kannada, Tamil, Telugu, Malayalam, Marathi, Bengali, Gujarati).

- **Tab 1**: enroll your own voice clones (8–30s sample)
- **Tab 2**: turn PPTX / PDF / TXT / Markdown into narrated audio + H.264 video + subtitles
- **Tab 3**: job monitor with checkpoint recovery

CPU-only, no API keys needed. Voice synthesis uses Microsoft Edge neural voices;
long videos render with automatic hardware/software encoder selection.
